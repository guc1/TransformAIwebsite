# Restrict package hover glow to CTA

- **What:** Limited the pricing table package glow to trigger only from the "View package deal" buttons in desktop and mobile layouts.
- **Why:** The glow previously remained active while hovering individual solution rows, which the client flagged as distracting.
- **Files:** `apps/www/components/pricing/pricing-compare-table.tsx`.
- **Follow-ups:** Review the hover effect with stakeholders once package detail pages receive real content.
