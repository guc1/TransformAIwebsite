# Mainboard light bars glow again
- **What:** Wrapped the animated light paths in the homepage mainboard SVG with a shared glow filter and introduced a reusable blur filter definition so the moving accents render as luminous streaks instead of flat blocks.
- **Why:** The refreshed artwork had lost the soft light effect, leaving the animation as solid rectangles and breaking the intended design.
- **Files:** `apps/www/images/mainboard.svg`.
