# Scrollable outreach filter controls

- **What:** Added scrollable containers and bulk action buttons to the outreach dashboard filters so long lists stay visible and teams can select or clear every option with one click.
- **Why:** More than four campaign or sub-segment options were clipped, preventing users from selecting or removing items beyond the first row.
- **Files:** `apps/www/app/[locale]/(site)/dashboard/components/outreach-manager.tsx`, `apps/www/messages/en.json`, `apps/www/messages/nl.json`.
- **Follow-ups:** None.
