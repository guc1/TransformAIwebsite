# WRITE_HERE workspace

This folder stores active working notes for the TransformAI project.

## Subfolders
- `UPDATES/` — feature, content, or workflow changes that affect behavior.
- `FIXES/` — bug fixes, user requests, and their technical resolutions.
- `TASK_PLANNING/` — planning notes for complex or multi-step tasks before execution.

## File naming
- All files must be Markdown (`.md`).
- Use the format `YYYY-MM-DDTHHMM--short-slug.md` (local 24h time).
- The first line of each file must be `# <Short, precise summary>` that humanizes the slug.
- Optionally add a metadata line such as `_When:_ … · _Scope:_ … · _Author:_ …`.

**Do not put secrets here.**
